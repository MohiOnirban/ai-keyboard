# Multi-Agent Engineering Strategy
Use GPT-6.2 Astra with Extra High reasoning as principal engineering coordinator where supported. Use parallel subagents for genuinely independent work, initially at most four concurrent subagents. Prefer GPT-6.2 Sol High for Android, iOS, Supabase backend, UI/UX and testing/debugging. Prefer GPT-6.2 Astra High for Bangladeshi communication intelligence and GPT-6.2 Astra Extra High for security/privacy review. Use GPT-6.2 Sol light for routine documentation and small tasks. Fall back to the closest supported configuration.
Establish architecture, API contracts, design tokens and acceptance criteria before parallel implementation. Assign exclusive file ownership. Principal reviews, integrates, builds and tests independently. Avoid duplicate work and unnecessary delegation. Continue through implementation and testing until functional or externally blocked.
Read docs/master.md for product requirements and shared/contract.md for integration. Use OpenRouter server-side for GPT-6 Luna. Run mock by default and use live AI only with an authorized budget.
