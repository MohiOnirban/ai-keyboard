# Keyboard v1
Android Kotlin IME and Compose companion, iOS UIKit extension and SwiftUI companion, Fastify TypeScript service, private PostgreSQL accounting. Anonymous HTTPS bearer token sessions. One configured backend base URL. Development port 4000. For emulator use 10.0.2.2, for simulator use localhost. Prototype name Kotha Keys.
POST /v1/sessions {} returns 201 {token:string}. GET /v1/usage with bearer returns {used:number,limit:number}. DELETE /v1/session revokes bearer and returns 204.
POST /v1/generate with bearer and Idempotency-Key UUID, JSON {mode:"rewrite"|"reply"|"express",text:string,style?:string,intensity?:"subtle"|"balanced"|"bold",relationship?:string,language?:"auto"|"bn"|"banglish"|"en",preferences?:{length?:string,humor?:string,formality?:string,emoji?:string,custom?:string}} returns 200 {suggestion:string,used:number,limit:number}. Non-2xx {error:string}, including 409 duplicate, 429 quota, 503 unavailable. Never persist response or draft server-side. Text max 1600 UTF-16 units.
Design tokens: light background #F5F6F2, key #FFFFFF, ink #172822, accent #116B58. Dark background #15221D, key #283B32, ink #EDF7F1, accent #75D8B8. System Bengali fallback, large accessible targets, accent for AI action, AI panel on demand.
Acceptance: offline English, Bengali, phonetic and raw typing; Unicode-safe editing; sensitive fields excluded; explicit AI preview and safe application, no sending; focus change cancels; full access optional; companion playground; private anonymous allowance; atomic caps; reproducible builds, automated tests and honest device evidence. See docs/master.md sections 17–20.
